Бортовой журнал — подключение

Личный журнал: еда с автоподсчётом КБЖУ, тренировки, английский, разбор рилсов, свои разделы. Пишешь в чат — Claude отвечает через пару минут.

Что нужно: ноутбук (шаги 1–7, минут 15) и телефон на Android (шаги 8–11). От Олега — токен для шага 6, он пришлёт в Telegram.

Важно: Олег видит записи твоего журнала. Claude работает на подписке Олега, поэтому есть лимит — примерно 10–15 ответов в сутки (обнуляется в 05:00 по твоему времени). Кончится — журнал работает как обычно, а Claude ответит на всё на следующий день.

5

Файл, который зовёт Claude сразу

💻 ноутбук

Без него Claude не узнает, что ты написал.

  1. В репозитории: Add file → Create new file.
  2. Имя файла (папки наберутся сами):
.github/workflows/claude.yml
  1. В большое поле вставь весь текст:
# Журнал: мгновенный ответ Claude.
# Новое сообщение с телефона → 90 секунд тишины (вдруг допишешь) → проверка лимита → запуск Claude.
# Ключ запуска — секреты CLAUDE_FIRE_TOKEN и CLAUDE_FIRE_URL (их даёт Олег). Без токена ничего не делает.
name: Claude

on:
  push:
    branches: [main]
    paths: [requests.json, ideas.json, 'inbox/**', recipes.json, 'money/**', pages.json]
  workflow_run:
    workflows: ['Видео по ссылкам']
    types: [completed]
  workflow_dispatch:

permissions:
  contents: write

jobs:
  fire:
    if: >-
      github.event_name == 'workflow_dispatch' ||
      (github.event_name == 'workflow_run' && github.event.workflow_run.conclusion == 'success') ||
      (github.event_name == 'push' && !contains(join(github.event.commits.*.message, ' | '), 'Разбор входящих') &&
       !contains(join(github.event.commits.*.message, ' | '), 'Claude:'))
    concurrency:
      group: claude-fire
      cancel-in-progress: true
    runs-on: ubuntu-latest
    timeout-minutes: 6
    steps:
      - name: Подождать, вдруг допишет
        if: github.event_name == 'push'
        run: sleep 90
      - uses: actions/checkout@v4
        with:
          ref: main
      - name: Проверить новое и лимит
        id: check
        run: |
          if [ -f .github/scripts/limit_check.py ]; then out="$(python3 .github/scripts/limit_check.py)"; else out="go"; fi
          echo "$out"
          case "$out" in go*) echo "go=1" >> "$GITHUB_OUTPUT";; esac
      - name: Запустить Claude
        if: steps.check.outputs.go == '1'
        env:
          TOKEN: ${{ secrets.CLAUDE_FIRE_TOKEN }}
          URL: ${{ secrets.CLAUDE_FIRE_URL }}
          REPO: ${{ github.repository }}
        run: |
          [ -n "$TOKEN" ] || { echo "::warning::Нет секрета CLAUDE_FIRE_TOKEN — Claude не запущен"; exit 0; }
          URL="$(echo "${URL:-https://api.anthropic.com/v1/claude_code/routines/trig_01L4uYq3bbAiM3X43D7xqSVZ/fire}" | tr -d '[:space:]')"
          code=$(curl -sS -o resp.json -w '%{http_code}' -X POST "$URL" \
            -H "Authorization: Bearer $TOKEN" \
            -H "anthropic-beta: experimental-cc-routine-2026-04-01" \
            -H "anthropic-version: 2023-06-01" \
            -H "Content-Type: application/json" \
            -d "{\"text\": \"repo: $REPO\"}")
          echo "Ответ: $code"
          [ "$code" = "200" ] || { head -c 300 resp.json; echo "::warning::Claude не запущен ($code)"; }
  1. Commit changes… → Commit changes.

Ключ для телефона

💻 ноутбук
  1. Открой
    https://github.com/settings/personal-access-tokens/new
  2. Token name:
    journal-phone
  3. Expiration: Custom → дата через год.
  4. Repository access: Only select repositories → journal-data.
  5. Permissions → Add permissions: Contents и Issues, у обоих Read and write.
  6. Generate token → скопируй (показывается один раз) и отправь себе в Telegram в «Избранное», чтобы вставить на телефоне.

Ключ никому не пересылай: с ним можно читать и менять твой журнал.

9

Первое сообщение Claude

📱 телефон

Нажми кнопку Claude (внизу справа) и напиши «Привет». Через 2–5 минут придёт ответ. В первый раз Claude сам подготовит журнал и спросит, с чего начать.

Нет ответа через 10 минут — ещё нет токена из шага 6 или Олег не принял приглашение. Сообщения не теряются: ответ придёт, когда всё подключится. Обнови журнал кнопкой ↻ вверху.

10

Как пользоваться

📱 телефон
  • Еда — вкладка «Еда» или в чат: «завтрак: овсянка 60 г, 2 яйца», можно фото тарелки. КБЖУ посчитается само, чего нет в таблице — оценит Claude. Цели на день: «подбери КБЖУ, вешу 80, хочу сушиться».
  • Тренировки — «составь программу»: Claude спросит цель, опыт, дни и где тренируешься. Подходы отмечаешь во вкладке «Спорт».
  • Английский — «хочу учить английский»: спросит уровень и сколько минут в какие дни, составит уроки во вкладке «Учёба».
  • Рилсы — в Instagram: самолётик → «Копировать ссылку» → вставь в чат Claude. Через пару минут он разберёт видео (кадры, подпись, речь) и предложит, что сделать: рецепт, упражнение, идея.
  • Свои разделы — «сделай раздел Вода: счётчик стаканов, цель 8, каждый день заново» или «чек-лист на утро». Появится кнопкой на «Плане».
  • Свои правила — «если пропустил тренировку, переноси на завтра». Claude запомнит.
  • Голосом — кнопка-микрофон в чате.
11

Рилсы через «Поделиться» (по желанию)

📱 телефон

Чтобы не копировать ссылку, а жать «Поделиться» прямо в Instagram:

  1. Сделай второй ключ как в шаге 7, но имя
    journal-share
    и только Issues: Read and write (Contents не давай).
  2. Поставь из Google Play бесплатное приложение HTTP Shortcuts.
  3. Создай ярлык Claude (обычный HTTP-запрос). Метод POST, адрес — вместо ЛОГИН твой логин GitHub:
https://api.github.com/repos/ЛОГИН/journal-data/issues
  1. Заголовки: Authorization = Bearer, пробел, ключ journal-share;
    Accept
    =
    application/vnd.github+json
  2. Раздел Переменные → новая переменная link → включи «получать значение из меню Поделиться».
  3. Тело запроса — JSON, вставь и замени LINK на переменную link (кнопка вставки переменной):
{"title": "Идея", "body": "LINK"}

Пользоваться: Instagram → Поделиться → HTTP Shortcuts → Claude. Через 1–2 минуты рилс будет в чате.

Obsidian на ноутбуке (по желанию)

💻 ноутбук

Если хочешь видеть журнал заметками. Claude после каждого ответа обновляет папку Журнал: еда, тренировки, английский, идеи, чат, твои разделы.

  1. GitHub Desktop:
    https://desktop.github.com
    → войди своим GitHub → Clone a repository → journal-data → папка, например Документы\journal-data.
  2. Obsidian:
    https://obsidian.md
    → Open folder as vault → эта папка. Заметки — в папке Журнал.
  3. Обновить: в GitHub Desktop Fetch origin → Pull origin.
  4. Чтобы обновлялось само: Obsidian → Settings → Community plugins → Browse → Obsidian Git → Install → Enable → Auto pull interval = 10. Плагину нужен Git:
    https://git-scm.com/download/win
    (установка «Далее, Далее»).

Заметки в «Журнал» руками не правь — перезапишутся. JSON-файлы в корне тоже не трогай: это данные журнала.

Если что-то не так
  • Журнал пишет «Не вижу репозиторий» — проверь шаг 7: ключ выдан на journal-data, есть Contents: Read and write.
  • Claude молчит дольше 10 минут — в репозитории вкладка Actions → «Claude»: красный крестик или жёлтое предупреждение — сделай скрин и отправь Олегу.
  • Рилс не скачался — Instagram иногда не отдаёт видео без входа. Claude так и скажет; пришли скрин или опиши словами.
