# Бортовой журнал — приложение (публичный код)

Веб-приложение журнала на GitHub Pages. Данные лежат отдельно, в приватном `gr0mbl4/journal-data` — их правила в его CLAUDE.md.

## Правила правок
- Репозиторий **публичный**: никаких данных из journal-data (траты, записи, имена, ключи, токены) сюда не переносить — ни в код, ни в коммиты.
- После правки `app.js` проверь синтаксис: `node -e "new Function(require('fs').readFileSync('app.js','utf8'))"`; если можешь — открой страницу в Chromium через Playwright.
- Подними версию: `app.js?v=…` в `index.html` и `CACHE` в `sw.js` — иначе телефон не подхватит новую версию.
- Правки — только однозначные и небольшие; большое или неясное — сначала спросить Олега.
- Никакого force-push.
