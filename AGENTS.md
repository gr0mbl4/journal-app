# Правила для ИИ-агентов

Все правила этого репозитория — в **CLAUDE.md**. Прочитай его целиком первым делом и следуй ему. Везде, где там написано «Claude», имеется в виду ты (Kimi, Codex, своя модель — любой агент).

Если ты не Claude: в ответах в чат журнала ставь в начале пометку, кто отвечал (`[Kimi]`, `[ПК]`). Правила безопасности из CLAUDE.md действуют без исключений.
