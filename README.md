# Бортовой журнал — страница

Личное приложение: план учёбы и тренировок с автоматическими переносами и учёт трат.

В этом репозитории только код страницы. Данных здесь нет: они лежат в отдельном приватном репозитории, и страница читает их через GitHub API по ключу, который хранится только в браузере телефона.

- `index.html` — разметка и стили; `app.js` — логика (вынесена отдельно, чтобы работала строгая политика безопасности CSP: страница может обращаться только к api.github.com).
- `manifest.webmanifest`, `*.png` — чтобы добавить на экран «Домой» как приложение.
- `sw.js` — офлайн-оболочка: страница и скрипт открываются из кэша без сети. Данные с GitHub в кэш сервис-воркера не попадают — они в localStorage (`bj-docs` — последние версии файлов, `bj-queue` — изменения, сделанные без сети; при связи они накладываются на свежие файлы трёхсторонним слиянием).
- Книги: аудио читается из отдельного приватного репозитория (`journal-books`) по тому же ключу, играет через `<audio>` с Media Session; последние главы кэшируются в Cache Storage (`bj-audio`).
- При выпуске новой версии меняй `app.js?v=…` в `index.html` и `CACHE` в `sw.js`.

Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
